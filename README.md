
# Superstore Sales Dashboard

Executive dashboard built using Python, Pandas, Matplotlib, and Seaborn.

## Project Overview

This project analyses the Superstore Sales dataset from Kaggle to discover business insights through Exploratory Data Analysis (EDA) and visualization.

## Dashboard Preview

![Dashboard](images/dashboard.png)

## Features

- KPI Summary
- Profit by Region
- Monthly Sales Trend
- Profit by Category
- Discount vs Profit
- Top Profitable Products
- Top Loyal Customers

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

https://www.kaggle.com/datasets/vivek468/superstore-dataset-final
